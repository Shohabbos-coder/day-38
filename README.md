# 💪 Workout Tracker App

A simple and effective workout tracking application to help you stay consistent and reach your fitness goals.

---

## 🚀 Features

- 📋 Log daily workouts and exercises
- 🏋️ Track sets, reps, and weights
- 📈 Monitor your progress over time
- 🗓️ View workout history by date
- 🔥 Streak tracking to stay motivated

---

## 🛠️ Tech Stack

- **Frontend:** Python
- **Backend:** Python
- **Other:** Node.js (time utilities)

---

## 📁 Project Structure

```
workout-tracker/
├── main.py       # Main application entry point
├── demo.py       # Demo / sample data
├── extra.py      # Helper functions
└── time.js       # Time and date utilities
```

---

## ⚙️ Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/workout-tracker.git
cd workout-tracker
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
npm install
```

3. **Run the app**
```bash
python main.py
```
